# WebOBJViewer
View OBJ files hosted locally on your web browser.

Instructions:
1. Open html file to launch webpage
2. Click "Load"
3. Drag all files related to your OBJ file.
   These can include the .obj, any linked .mtl files,
   and any linked pictures in .jpg or .png format.
4. Use your mouse or finger to drag the object around to
   view it from any angle.
